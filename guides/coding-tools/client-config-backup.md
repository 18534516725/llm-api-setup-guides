# AI 编程客户端配置如何备份：Key、模型和工作区分开保存

**直接结论：备份配置时把凭证和非敏感配置分开。不要把包含 API Key 的完整目录直接提交到 Git。**

## 建议分类

| 内容 | 是否进入 Git |
|---|---|
| 模型名、非敏感参数 | 可以，先审查 |
| API Key、Cookie、Token | 禁止 |
| 工作区规则和提示词 | 可以，注意隐私 |
| 会话、日志、缓存 | 通常不应提交 |

## 恢复验证

1. 先撤销旧 Key 或使用专用测试 Key。
2. 恢复非敏感配置。
3. 重新设置凭证并验证权限。
4. 在空工作区完成最小文本和只读任务。
5. 检查 `git diff`、日志和外发请求。

配置备份还应记录客户端版本和字段来源，否则升级后可能无法判断哪项设置失效。

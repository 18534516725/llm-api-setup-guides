# AI API 上线前健康检查：认证、模型、流式与账单四项验证

**直接结论：上线前至少通过四项检查：认证成功、模型可用、流式完整、用量可核对。只测一次普通聊天不够。**

## 冒烟顺序

1. 使用专用测试 Key 请求模型列表或服务规定的发现接口。
2. 发送短文本请求，确认模型 ID 和协议匹配。
3. 开启流式，记录首个事件、结束事件和中断情况。
4. 执行一次最小工具调用或结构化输出测试（若业务需要）。
5. 在控制台核对请求、Token、费用和错误记录。

## 通过标准

- 失败时能区分认证、路径、模型、额度和协议错误；
- 测试 Key 可以单独撤销；
- 结果带有测试时间、版本和环境；
- 不在报告中保存完整 Key、请求正文或内部路由信息。
